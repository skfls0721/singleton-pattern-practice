# Singleton 패턴 실습

## 선택 언어와 실행 환경

- 언어: Python
- 실행 환경: Python 3.9.6
- 별도 패키지 설치는 필요하지 않습니다.

## 실행 방법

저장소 폴더에서 다음 명령을 실행합니다.

```bash
python3 singleton.py
```

## 실행 결과

```text
같은 인스턴스인가요? True
첫 번째 변수에서 설정한 counter: 42
두 번째 변수에서 읽은 counter: 42
```

## 구현 설명

`AppSettings` 클래스의 `_instance` 클래스 변수에 싱글톤 객체를 보관합니다. `AppSettings()`가 호출될 때마다 `__new__`가 `_instance`를 확인하고, 아직 객체가 없을 때에만 새 객체를 생성해 저장합니다. 이미 객체가 있으면 저장된 객체를 그대로 반환하므로 반복 요청으로 새 객체가 만들어지지 않습니다. 실행 결과에서 `first is second`가 `True`이고, `first`로 바꾼 `counter` 값이 `second`에서도 42로 읽히므로 두 변수가 같은 객체와 상태를 공유함을 확인할 수 있습니다.

이 예제는 과제 조건에 맞춰 단일 프로세스·단일 스레드 환경을 가정합니다.
